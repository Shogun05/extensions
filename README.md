# Shogun05 Extensions

MangaRaw (Japanese) source code is maintained in [Shogun05/extensions-source](https://github.com/Shogun05/extensions-source).

## APK builds

GitHub Actions builds the extension APK:

1. Open [Build MangaRaw APK](https://github.com/Shogun05/extensions-source/actions/workflows/build_mangaraw.yml).
2. Select a successful run.
3. Download the `mangaraw-apk` artifact, extract it, and install the APK on your phone.

This repository has no published extensions yet. Its catalogue is empty until an Actions-built APK is published with matching catalogue metadata.
